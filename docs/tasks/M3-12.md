# M3-12 — M3 exit demo, walkthrough, and §21.3 acceptance

## Objective
`docs/demos/M3.md`: a walkthrough that imports a sample character and a sector, then completes one
locally rendered trade turn with historical remote pricing — run from a clean checkout.

## Context
Plan §5's required M3 exit demo, verbatim: "M3 imports a sample character and sector, then
completes one locally rendered trade turn with historical remote pricing." Plan §6.2: from M3
onward there is no milestone PR, so the walkthrough **stands alone as the closure checkpoint**
against current `main`. A milestone does not close until its demo passes and its retro is written.

Spec §21.3's M3 acceptance list, all three of which this card must demonstrate:
1. Traveller import round-trips travtools JSON
2. INV-9 green over imported sector data
3. trust-mode path tested with no data loaded

**Run record honesty is not optional.** M2's demo doc shipped with a blank Run record and an
explicit "this walkthrough has not been run" note, and that was the right call — a fabricated
pass is worse than an honest blank. BL-10 and BL-11 were both found by finally running the thing.
Author the walkthrough, run what can be run locally, and leave the owner's line blank until the
owner runs it.
