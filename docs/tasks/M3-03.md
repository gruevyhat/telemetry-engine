# M3-03 — Engine plugin API: TravelModel, Ship, and character contracts

## Objective
Grow `packages/engine/src/plugin-api` from today's economy-only slice to the interfaces M3 needs
— `TravelModel`, `Ship`, `CrewMember`, `CharacterSchema`, `EdgeDef` — so engine code can consume
travel and crew without ever importing the Traveller plugin.

## Context
`packages/engine/src/plugin-api/index.ts` currently declares only `EconomyPluginApi { goods }`,
and its own comment says the rest of Spec §15's `Plugin` "is out of scope here; each slice is
added incrementally by the task that needs it." M3 is that task. This is the INV-1 boundary: the
engine defines the contract, `plugin-traveller` implements it, and `pnpm build:stub` must keep
passing with `plugin-traveller` deleted.

Frontier work — public interface design, forbidden to workers per CLAUDE.md.

## Owned paths
- `packages/engine/src/plugin-api/index.ts`
- `packages/engine/src/plugin-api/travel.ts`
- `packages/engine/src/plugin-api/character.ts`

## Read context
- `docs/design/travel-and-import-v1.md` (M3-00)
- Spec §15 (the `Plugin`/`TravelModel` interfaces as written), Spec §1 (INV-1)
- `packages/engine/src/plugin-api/index.ts` (current shape and its incremental-growth note)
- `packages/engine/src/render/feed.ts` — `FeedDistance = number | "unknown"`, the existing
  consumer of a distance value

## Acceptance tests
`packages/engine/src/plugin-api/plugin-api.test.ts` — lead-authored at dispatch. Cases:
- type-level: a conforming stub implementation satisfies `TravelModel` and `CharacterSchema`
  (compile-time assertions with `@ts-expect-error` on deliberately non-conforming shapes)
- `distance` is typed to return `number | 'unknown'`, so trust mode is representable in the type
  system rather than by convention
- no module under `packages/engine/src` imports from `plugin-traveller` or `content/` (existing
  INV-1 guard extended to the new files)

## Verification
- `pnpm test && pnpm typecheck && pnpm lint`
- `pnpm build:stub` — the INV-1 proof, must stay green

## Non-goals
- Implementing any of these interfaces — that is M3-01/02/06/07 in `plugin-traveller`
- `persona`, `dice`, `careerEdges` wiring into a full `Plugin` object — that is M3-11

## Do not
- Import from `plugin-traveller/` or `content/` anywhere in `packages/engine` (INV-1)
- Add a dependency to `packages/engine` without owner sign-off
