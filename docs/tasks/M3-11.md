# M3-11 — Traveller plugin assembly: a real Plugin object

## Objective
`packages/plugin-traveller` stops being `export {}` and becomes a real Spec §15 `Plugin` the app
registers and uses.

## Context
Every M3 packet before this one builds a piece in isolation: hex math, SEC parsing, travel, the
character importer, edges. Nothing assembles them into the `Plugin` object Spec §15 declares
(`id`, `persona`, `dice`, `characterSchema`, `importCharacter`, `careerEdges`, `economy`,
`travel`), and nothing registers that plugin with the running app.

**This card exists because M1 and M2 both learned the same lesson the hard way.** M1-13 and
M2-15 each discovered mid-milestone that no earlier card had actually assembled the shipped
pieces into a runnable whole; the M1 retro turned that into a Plan §5 rule — a task standing up a
whole new package or assembly surface is split out at planning time. `plugin-traveller` is
exactly that surface, so the split is made here, up front, rather than discovered late.

Frontier: public interface assembly plus the INV-1 boundary.

## Acceptance tests
`packages/plugin-traveller/src/index.test.ts` — lead-authored at dispatch. Cases:
- the exported plugin satisfies the full §15 `Plugin` interface (type-level plus runtime shape)
- `importCharacter` on a fixture yields the same `CrewMember` as calling M3-07 directly — the
  assembly adds no behavior of its own
- `travel.distance` on fixture hexes matches M3-01 directly; `stalenessWeeks` matches Spec §7.2
- with no sector loaded, the assembled plugin reports `'unknown'` distance (trust mode survives
  assembly)
- `dice.check` follows the standard 2d6 convention with characteristic DM and skill level, on a
  hand-checked table including a critical success and failure
- persona/lexicon strings pass `pnpm lint:content`
- **INV-1: `pnpm build:stub` passes with `plugin-traveller` deleted** — the IP proof, unchanged

## Verification
- `pnpm test && pnpm typecheck && pnpm lint && pnpm lint:content`
- `pnpm build:stub` (INV-1) and `pnpm build:pages`

## Non-goals

- Any second plugin

## Do not
- Let `packages/engine` import this package (INV-1) — the dependency points one way
- Put rulebook table prose in content files; original entries and dice math only (Spec §15
  fair-use hygiene). The Mongoose disclaimer stays in this README and the app footer.
