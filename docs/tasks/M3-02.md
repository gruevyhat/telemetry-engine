# M3-02 — SEC sector-file parser

## Objective
Parse a travellermap.com SEC export into typed world records, so an imported sector becomes data
the travel model and feed can use.

## Context
Spec §15: "sector data via a one-time user-driven import of travellermap.com SEC export, stored
locally (static-hosting compliant, offline thereafter)." SEC is a fixed-column text format: name,
hex, UWP, trade codes, PBG, allegiance, stellar data. Real exports contain comment lines, header
separators, blank lines, and inconsistent trailing whitespace — the parser must survive all of
it, because the file comes from a user's download, not from us.

Per M3-00, the committed fixture is a **fictional** sector with invented names and UWPs. Real
travellermap files are imported by the user at runtime and never enter the repo.

## Owned paths
- `packages/plugin-traveller/src/sec.ts`
- `packages/plugin-traveller/fixtures/fictional-sector.sec`

## Acceptance tests
`packages/plugin-traveller/src/sec.test.ts` — lead-authored at dispatch, worker read-only. Cases:
- parses the fictional fixture into the expected world count with exact field values on a
  hand-checked sample row (name, hex, UWP, trade codes, PBG, allegiance)
- comment lines, header/separator lines, blank lines, and trailing whitespace are skipped, not
  parsed as worlds
- a malformed row yields a typed parse error naming the offending line number, and does not
  abort the whole file — good rows still parse and bad rows are reported
- a duplicate hex in one file is reported rather than silently last-one-wins
- parsing is pure and idempotent: same input, byte-identical output, twice
- UWP fields decompose correctly (starport, size, atmosphere, hydrographics, population,
  government, law, tech) including the hex-digit values above 9

## Verification
- `pnpm test -- packages/plugin-traveller/src/sec.test.ts`
- `pnpm typecheck`
- `pnpm lint`
- `pnpm build:stub`

## Non-goals
- Persisting the parsed sector — that is M3-04
- Any other travellermap format (tab-delimited T5 second survey, JSON API)
- Interpreting trade codes into economic effects

## Do not
- Commit any real travellermap data; the fixture is fictional and original per M3-00
- Add a dependency (no CSV/parser libraries — this is fixed-column text)
